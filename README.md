## Description
A multi-page website about HTML forms, HTML5 validation and Bootstrap 5.3 form components. Every page has a navbar linking to all tasks.

| Page | Task |
| --- | --- |
| `index.html` | Task 0. Simple contact form with labels |
| `task1.html` | Task 1. HTML5 validation (`required`, `type`, `minlength`, `maxlength`, `pattern`, `min`/`max`) |
| `task2.html` | Task 2. Bootstrap styling, grid, placeholders, helper text |
| `task3.html` | Task 3. Bootstrap validation (`is-valid` / `is-invalid`, feedback messages) |
| `task4.html` | Task 4. Registration form: grid, HTML5 + Bootstrap validation, Reset |

## Structure
```
README.md
index.html
task1.html
task2.html
task3.html
task4.html
style.css
```

No JavaScript is used. Validation is done with HTML5 attributes and Bootstrap's `was-validated` class.

## How to run
1. Clone the repository or download the ZIP.
2. Open `index.html` in a browser (internet is needed for the Bootstrap CDN).

## How to publish (GitHub Pages)
Repository -> Settings -> Pages -> Source: `main` branch, `/ (root)` -> Save.
